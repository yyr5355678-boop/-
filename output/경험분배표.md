예시 연결:
- 리조트 메뉴 수요 예측 → 생산 라인 수요 예측, 재고 최적화
- RMSE 55.9% 개선 → 불량률 예측 모델 정밀도 개선
- 학습 시간 90배 단축 → 생산 데이터 분석 사이클 단축
